# GDG Project - AI Agent Instructions

## Project
This is a React + Vite project being developed for a GDG Campus selection project.

## Rules

It should not look like ai generated
- Use React and JavaScript.
- Do not introduce TypeScript unless explicitly requested.
- Keep the existing project structure.
- Reuse existing components before creating duplicates.
- Keep components modular and reusable.
- Do not delete working functionality without explicit permission.
- Do not change the project architecture without discussing it first.
- Do not install new packages unless they are necessary.
- Before modifying a file, understand its existing code.
- Keep UI responsive for desktop and mobile.
- Keep the code clean and readable.
- Do not hardcode secrets, API keys, passwords, or tokens.
- Never commit `.env` files containing secrets.
- Test the application after significant changes.
- Do not modify unrelated files.

## Git Rules

- Work on a feature branch when implementing a significant feature.
- Never use `git push --force` unless explicitly instructed.
- Make small, descriptive commits.
- Do not rewrite existing Git history.
- Do not commit broken code intentionally.

## Collaboration

Multiple AI coding agents may work on this project.

Before implementing a feature:
1. Inspect the existing code.
2. Identify which files need modification.
3. Avoid unnecessary changes outside the requested feature.
4. Explain what was changed.
5. Report any dependencies or assumptions.
